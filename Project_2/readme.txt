
1)
Website-ul este despre o firma fictiva ce se ocupa cu vânzarea de audiosisteme si totodata are si abonamente lunare ce ofera utilizatorilor acces la procesarea audio a cantecelor pentru separarea acestora in stem-uri (vocal, instrumantal, bass, drums, etc.)




2)
	-Pagina servicii.html (de aici se pot cumpara audiosistemele)
	-Pagina price_calculator.html (calculeaza costul total, livrarea si taxa in dependenta de cate audiosisteme cumpara utilizatorul)
	-Pagina preturi.html (aici sunt ofertele de abonamente lunare pentru diferite categorii de utilizatori)
	-Pagina aboutus.html (aici este o mica descriere a firmei)
	-Pagina contacte.html (aici se gaseste adresa, email-ul si telefonul companiei)




3)
Cu javascript se genereaza o parte din tabelul in care se calculeaza costurile pentru achizitia de audiosisteme.
Iar functiile Javascript calculeaza taxa, livrarea si costul audiosistemelor in dependenta de numarul de camere pe care le introduce utilizatorul de la tastatura.




4)
Site-ul are mai intai pagina principala care este home.html, iar de acolo se pot accesa pe rand toate paginile secundare.
In pagina secundara servicii.html, apasand pe butonul "Calculate price for your system" se pot calcula costurile unui audiosistem cu ajutorul functiilor javascript.
Site-ul este in mare parte intuitiv si usor de folosit.
